# Quiz interactivo: regresión y correlación

Aplicación web educativa autocontenida para estudiantes universitarios.

- 20 preguntas aleatorias
- Calificación automática sobre 100
- Diseño adaptable a celulares, tabletas y computadoras
- Funciona sin dependencias externas

La versión docente, la clave y las soluciones no se publican en este repositorio.
